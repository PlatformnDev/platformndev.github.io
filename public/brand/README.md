- 확인일: 2026-09-18
- 홈페이지: https://platformn.kr/
- 원본 자산: https://framerusercontent.com/images/lmwBkejR8Z4NzQyCVyryGPOesHc.png?scale-down-to=512&width=1393&height=205
- `platformn-icon.png`: 홈페이지 파비콘 원본 https://framerusercontent.com/images/aNuPAmbC97QPa2okVKTPOM0zg.png
- 로고의 색상과 비율을 유지합니다. 회사 CI에 대한 권리는 플랫폼엔에 있습니다.

브라우저에서 외부 이미지 요청 없이 표시하도록 로컬에 보관합니다. 전체 사이트 빌드 시 `public/brand/`를 루트 `brand/`에도 복사해 도구 목록과 배경 제거 앱에서 함께 사용합니다.
